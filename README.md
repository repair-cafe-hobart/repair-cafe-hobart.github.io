# Repair Café Hobart website

The live site is at <https://repair-cafe-hobart.github.io/>. It is a static site with no build step.

## Site files

- `index.html` contains the page content and navigation.
- `styles.css` controls the layout, colours and responsive design.
- `script.js` controls the small-screen navigation menu.
- `rch-logo-facebook.jpg` is the current social-media logo.
- `repair-cafe-posters.jpg` is the supplied photo of Repair Café posters.

## Keep event information current

Before each session, confirm the date, time, venue and access details in `index.html`. The current page lists Saturday 17 October 2026, 1–4 pm at Kickstart Arts Inc, 12 St John’s Avenue, New Town. Check whether any booking or visitor instructions need to be added.

## Connect volunteer signup

The volunteer buttons currently open an email to the public contact address. When the public roster signup form is ready, update those button links in `index.html` to its URL. Do not commit the roster workbook or volunteers’ personal details to this public repository.

## GitHub Pages

This repository, `repair-cafe-hobart.github.io`, publishes from the `main` branch at the repository root. HTTPS is required for the default GitHub Pages address. A custom domain is optional.
